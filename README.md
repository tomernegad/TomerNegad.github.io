# Tomer Negad - Portfolio

A modern, responsive portfolio website built with React and Vite, featuring 3D animations and a sleek design.

## Features

- **Hero Section** with 3D hologram effects
- **About Section** highlighting professional background
- **Skills Section** with animated progress bars
- **Projects Section** showcasing GitHub repositories
- **Contact Section** with contact form and social links
- Responsive design with dark theme and neon accents
- Smooth scrolling and animations using Framer Motion
- 3D elements powered by React Three Fiber

## Technologies Used

- React 19
- Vite
- Framer Motion
- React Three Fiber
- Three.js
- Tailwind CSS (via custom styles)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`

## Deployment

This project is configured for deployment to GitHub Pages with automatic builds via GitHub Actions.
